# hello

Workspace for an econometrics / empirical economics paper.

## Layout
- data: raw (immutable), interim, processed, external, codebooks
- sources: estimation code (Stata/R/Python), cleaning, robustness
- results: regression tables, figures, diagnostics, robustness checks
- visualization: charts and diagrams
- literature: references (bib), pdfs, notes, prose drafts
- chronology: timeline of events, policy dates, data vintages, work log
- latex: manuscript sources
- replication: package for journal replication requirements
- reports, dport, submission, template
